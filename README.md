## Overview

The Smart Restaurant with E-Menu Card is an embedded systems project designed to automate the food ordering process in restaurants. The system replaces traditional manual order-taking methods with a wireless solution using Bluetooth communication, reducing human errors and improving operational efficiency.

## Features

* Wireless food ordering using Bluetooth HC-05
* Android-based digital menu interface
* Real-time order transmission
* Reduced manual errors in order processing
* Faster customer service and reduced waiting time
* Cost-effective and scalable solution

## Hardware Components

* Arduino Uno
* HC-05 Bluetooth Module
* 16×2 LCD Display
* Power Supply Circuit
* Android Application

## Working Principle

1. Customers browse the menu using the Android application.
2. Food orders are sent wirelessly through Bluetooth HC-05.
3. Arduino receives and processes the order.
4. Order details are displayed on the LCD screen.
5. Restaurant staff prepare and deliver the order.
